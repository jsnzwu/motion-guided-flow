# config

Project-specific configuration dataclasses and helpers.

## Contents
- `moflow_components.py`: Defines `MFRRTaskConfig` and related dataclasses (e.g., `FGDatasetConfig`, `FGModelConfig`), registered in `wickit.config.CONFIGS`.
- `moflow_config_utils.py`: Wrapper helpers returning `MFRRTaskConfig` from parsed YAML.
